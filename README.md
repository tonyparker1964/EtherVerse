# EtherVerse (EV)

Ether's project universe: every app orbits Ether's sun.

**Visit:** https://tonyparker1964.github.io/EtherVerse/

## The worlds
- **Ether's Field** (Venus): a sound-reactive visualizer with cymatics, chakra tones and a live solar system. [Open](https://tonyparker1964.github.io/Ethers-field/)
- **Ether Beat Lab** (Jupiter): a browser beat maker with nine genres, pads, a sampler and exports for Ether Cut. [Open](https://tonyparker1964.github.io/Ether-Beat-Lab/)
- **Ether Cut** (Neptune): a browser music-video editor. [Code](https://github.com/tonyparker1964/Ether-s-Cut)
- **Ether Image Studio** (Uranus): 146 looks from around the world, blended into image and motion prompts. [Open](https://tonyparker1964.github.io/Ether-Image-Studio/)
- **The Zero's Journey** (Earth, with the Moon as v2): a personal-growth app in nine stages. Private.
- **Tribe Xchange** (Mars): a SwiftUI app for community trading with time tokens. Private.
- **Alignment** (Saturn, with Titan as 1.0): a personal app. Private.
- **Mercury and Pluto** are kept open for future projects.

The public projects in "All repositories" update live from the GitHub API.
